       - Interface `OAuth1Credentials`: `{ apiKey: string; apiSecret: string; accessToken: string; accessSecret: string }`.
       - Interface `OAuth1Request`: `{ method: string; url: string; params?: Record<string, string> }`.
       - Percent-encoding helper following RFC 3986 (encode characters `!*()'`).
       - Generate `oauth_nonce` via `crypto.randomBytes(16).toString('hex')`.
       - Generate `oauth_timestamp` via `Math.floor(Date.now() / 1000).toString()`.
       - Combine oauth parameters (`oauth_consumer_key`, `oauth_nonce`, `oauth_signature_method="HMAC-SHA1"`, `oauth_timestamp`, `oauth_token`, `oauth_version="1.0"`) with optional request query/body parameters.
       - Sort parameters lexicographically by percent-encoded key and then by value.
       - Create parameter string: `k=v&k2=v2...`.
       - Create signature base string: `${method.toUpperCase()}&${rfc3986(baseUrl)}&${rfc3986(parameterString)}`.
       - Signing key: `${rfc3986(apiSecret)}&${rfc3986(accessSecret)}`.
       - Compute HMAC-SHA1 using `crypto.createHmac('sha1', signingKey).update(signatureBaseString).digest('base64')`.
