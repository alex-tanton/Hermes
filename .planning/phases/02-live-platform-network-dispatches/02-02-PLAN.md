         - Extract `access_token = tokenData.access_token`.
       - Step B (Submit Post or Comment):
         - If `target.type === 'comment'`:
           - Endpoint: `https://oauth.reddit.com/api/comment`.

         - If `target.type === 'post'` or other:
           - Endpoint: `https://oauth.reddit.com/api/submit`.
           - Body params: `api_type=json`, `sr=target.name`, `kind=self`, `title=payload.title`, `text=payload.formattedContent`. If `target.flair` is set, add `flair_id=target.flair`.

           - `Authorization`: `Bearer ${access_token}`
           - `User-Agent`: userAgent
           - `Content-Type`: `application/x-www-form-urlencoded`
         - Signal: `AbortSignal.timeout(10000)`.
         - If response.ok is false: return createErrorResult(payload, `Reddit submission failed [HTTP ${response.status}]: ${await response.text()}`, destination).
         - Parse Reddit JSON response:
           - Check `data.json.errors`: if non-empty, format error message `Reddit API error: ${data.json.errors.map(e => e.join(': ')).join('; ')}` and return createErrorResult.
           - Extract post/comment metadata: `postId = data.json.data.name || data.json.data.id`, `postUrl = data.json.data.url || \`https://www.reddit.com/r/\${target.name}/comments/\${postId}\``.
         - Return successful PostResult with postId, postUrl, simulated: false, targetDestination: destination.
