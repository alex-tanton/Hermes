<task>
<task_header>
Task 1: Multi-stage Dockerfile and .dockerignore (PROD-01)
</task_header>

<task_description>
1. Create `.dockerignore` in the project root ignoring:
   - `node_modules`
   - `dist`
   - `.git`
   - `.husky`
   - `.data`
   - `logs`
   - `.env`
   - `tests`
   - `.planning`
   - `*.log`
   - `.DS_Store` / `Thumbs.db`

2. Create `Dockerfile` in the project root using a lightweight multi-stage build:
   - **Stage 1 (`builder`)**:
     - Base: `node:20-alpine`
     - Workdir: `/app`
     - Copy `package*.json`
     - Run `npm ci`
     - Copy `tsconfig.json` and `src/`
     - Run `npm run build`
   - **Stage 2 (`runner`)**:
     - Base: `node:20-alpine`
     - Workdir: `/app`
     - Set `ENV NODE_ENV=production`
     - Copy `package*.json`
     - Run `npm ci --omit=dev`
     - Copy compiled `dist` from builder stage (`COPY --from=builder /app/dist ./dist`)
     - Ensure `/app/.data` and `/app/logs` directories exist with ownership for `node:node`
     - Set `USER node` for non-root security
     - Declare volumes `["/app/.data", "/app/logs"]`
     - Set default `CMD ["node", "dist/cli/index.js", "daemon"]`
</task_description>

<verification>
File existence check and automated spec validation in tests/packaging.test.ts.
</verification>

<rollback>
Remove `Dockerfile` and `.dockerignore`.
</rollback>
</task>

<task_header>
Task 2: Docker Compose Configuration (PROD-01)
</task_header>

<task_description>
Create `docker-compose.yml` in the project root:
- Define service `referral-repeater`
- Set `build` context to `.` and dockerfile `Dockerfile`
- Tag image as `referral-repeater:latest`
- Container name: `referral-repeater`
- Set `restart: unless-stopped`
- Enable `init: true` for clean PID 1 signal forwarding and zombie reaping
- Environment: `NODE_ENV=production`
- Optional env file: `.env`
- Host volume mounts:
  - `./config.yaml:/app/config.yaml:ro`
  - `./.data:/app/.data`
  - `./logs:/app/logs`
- JSON file logging configuration with `max-size: "10m"` and `max-file: "3"` to prevent disk exhaustion.
</task_description>

Verify YAML syntax and property validity using `yaml` parser in tests/packaging.test.ts.
</verification>

<task>
<task_header>
Task 3: PM2 Ecosystem & Linux Systemd Service Template (PROD-02) & Automated Packaging Test Suite
</task_header>

<task_description>
1. Create `ecosystem.config.cjs` in the project root:
   - Export CommonJS configuration object with `apps` array.
   - App name: `'referral-repeater'`
   - Script: `'./dist/cli/index.js'`
   - Args: `'daemon'`
   - `instances: 1`
   - `autorestart: true`
   - `watch: false`
   - `max_memory_restart: '300M'`
   - `env: { NODE_ENV: 'production' }`
   - Output logs to `'./logs/pm2-out.log'` and errors to `'./logs/pm2-error.log'`
   - Enable timestamps (`time: true`) and `merge_logs: true`

2. Create `referral-repeater.service` systemd unit file in the project root:
   - `[Unit]` with description, documentation link, `After=network-online.target`, and `Wants=network-online.target`
   - `[Service]` with `Type=simple`, default `User=referral-repeater`, `WorkingDirectory=/opt/referral-repeater`, `ExecStart=/usr/bin/node /opt/referral-repeater/dist/cli/index.js daemon`, `Restart=always`, `RestartSec=10`, `Environment=NODE_ENV=production`
   - Systemd security hardening: `NoNewPrivileges=true`, `ProtectSystem=strict`, `ReadWritePaths=/opt/referral-repeater/.data /opt/referral-repeater/logs`, `ReadOnlyPaths=/opt/referral-repeater/config.yaml`
   - `[Install]` with `WantedBy=multi-user.target`

3. Create `tests/packaging.test.ts`:
   - Test Dockerfile stages, non-root user, CMD, and multi-stage copying.
   - Test .dockerignore exclusions.
   - Test docker-compose.yml schema, volume bindings, restart policy, and init flag.
   - Test ecosystem.config.cjs CommonJS loading, memory limits, and process args.
   - Test referral-repeater.service sections, ExecStart target, and restart settings.
</task_description>
