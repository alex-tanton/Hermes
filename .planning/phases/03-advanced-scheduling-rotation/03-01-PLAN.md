         After filtering links by `enabled`, `filterCategory`, `targetPlatforms`, and `isCoolingDown`:
         Sort the remaining eligible links with deterministic multi-level criteria:
         ```typescript
         return eligible.sort((a, b) => {
           const priorityA = a.priority ?? 50;
           const priorityB = b.priority ?? 50;
           if (priorityA !== priorityB) {
             return priorityB - priorityA; // higher priority first
           }
           const lastA = this.history.getLastPostTime(a.id, platform) ?? 0;
           const lastB = this.history.getLastPostTime(b.id, platform) ?? 0;
           return lastA - lastB; // least recently posted (or never posted) first -> fair rotation
         });
         ```
       - This guarantees that when links have equal priority, the link that has gone the longest without being posted to this platform is chosen first.
